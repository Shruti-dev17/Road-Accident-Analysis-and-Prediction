# Road Accident Analysis and Prediction

## About the Project

Road Accident Analysis and Prediction is a data analysis and machine learning project developed using Python and Django. 
It analyzes road accident patterns, identifies accident-prone areas, explores contributing factors, and predicts accident severity based on selected accident-related inputs.

## Features

* **Accident pattern Analysis:** Analyze accident patterns by year, time, and period.
* **State-wise Analysis:** Explore accident distribution across Indian states.
* **Severity Analysis:** Examine accident severity in relation to road conditions and other factors.
* **Contributing Factors:** Analyze weather,alcohol involvement, vehicle types, and road conditions.
* **Interactive Dashboard:** Visualize accident data through graphs and heatmaps.
* **Machine Learning Prediction:** Predict accident severity using a trained Random Forest classifier.
* **Feature Importance:** Explore the features used by the trained model.

## Dataset

The project uses an India road accident dataset for accident analysis and predictive modeling.

Dataset source: [India Road Accident Dataset – Kaggle](https://www.kaggle.com/datasets/khushikyad001/india-road-accident-dataset-predictive-analysis)

## Machine Learning

A Random Forest classifier is used to predict accident severity. The model is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.

**Note:** Predictions are estimates based on the trained model and available data. They should not be treated as guarantees of accident outcomes.
